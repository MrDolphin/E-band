## 现场约束与解释

- 当前两只喇叭、单 RX 链路只能提供距离检测；界面中的方位扫描图是演示动画，不是实测方位。
- 速度仅在跨 chirp 相位稳定且检测可靠时有效；显示“速度不可置信”是正常保护，不应当作速度测量。
- 室内墙面、支架和线缆会形成多径。应记录“放入—移走—放回”三次变化，而非仅根据一次目标点判定成功。
- `chirp correlation is below the sync threshold` 表示当前 CPI 未达到同步门限；先保存日志和 IQ（如已启用），再检查 TX 是否持续、RX RMS、天线指向与桥接进程占用。
